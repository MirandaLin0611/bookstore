# 生活情境分類

首頁保留七個快捷入口，透過「看全部生活情境」展開六組、共 32 種選項。年齡、語言、階段、風格仍可一起使用。投稿表單使用同一份情境清單，選填即可。

## 參考網站與取捨

檢視日期：2026-11-12。

- [博客來：圖畫書／生活教育](https://www.books.com.tw/web/sys_bbotm/books/140403/)及[親情／友誼](https://www.books.com.tw/web/sys_bbotm/books/140401/)：以生活教育與關係作為書籍分類，再搭配排序。本站將家長常見的需求細分成可直接選取的情境。
- [BooksForTopics](https://www.booksfortopics.com/)：按年齡、主題、生活經驗整理書單；友誼、同理、善意、入學與生活轉變各有入口。本站採用分組與逐步展開，讓情境增加時仍方便瀏覽。
- [BookTrust Bookfinder](https://www.booktrust.org.uk/book-recommendations/bookfinder/)：將年齡與主題、類型分開選擇。本站沿用年齡與情境分開篩選的方式，年齡仍依家長投票。

以下分類是依本站的親子共讀需求整理，並非上述網站的原分類全文。沒有增加商品價格、庫存等不適合現階段推薦平台的條件。

## 篩選與資料

- 多選情境需全部符合，再加上年齡、語言等條件；這與既有主題篩選一致。首頁快捷入口會替換原本的情境／階段，其他條件維持。
- 每個選項的數字是**該情境的公開繪本總數**，不隨其他條件變動。書籍同時有標籤和階段投票也只計算一次，審核中與下架書籍不計入。
- 沒有推薦的情境顯示 0，仍可選取；不自動替書籍補標籤，也不因心得碰巧出現某個字就歸類。家長能清除條件後繼續找書。
- 相近標籤共用一個選項，例如「道歉／對不起 → 學說對不起」、「禮貌 → 有禮貌」、「手足關係 → 手足相處」、「感恩／感激／感謝 → 感恩與感激」。搜尋文字也能找到這些相近用語。
- 沿用既有情緒、睡前等階段投票；只有「情緒管理」的書不會被推斷成「道歉」，只有「親子互動」也不會被推斷成「手足相處」。
- 既有自訂主題保留在「其他主題」；投稿也能輸入清單之外的主題。

新投稿將勾選情境與手填主題合併、統一已知別名並去除重複，寫入既有 books.themes。選到對應既有階段的情境時，也一併寫入 suggested_stages，沿用核准後建立作者建議的既有流程；只使用資料庫已允許的階段值。

**不需資料庫遷移或重跑 SQL。** 既有書籍不會被改寫。送出失敗會保留所選情境，成功才清空。
