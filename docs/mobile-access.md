# 手機回訪與文字草稿

## 更新網站

已套用先前資料庫補丁的網站，本次不需 SQL 或新服務。把完整 ZIP 上傳到 Cloudflare → Workers & Pages → bookpebble → Deployments → New deployment，部署後重新整理原網址。

ZIP 包含 `index.html`、`styles.css`、`config.js`、`mobile.js`、`manifest.webmanifest`、`assets/reading-garden.svg`、`assets/bookpebble-icon.png`，保持相對位置。圖示沿用網站現有的書本與嫩芽圖案。

## 從手機主畫面回來

手機首頁提供「加入主畫面」，頁尾也有相同說明入口。只在使用者點擊後顯示，不會自動彈出。從主畫面版本打開時，這些提示會隱藏。

### iPhone／iPad

1. 先用 Safari 開啟 https://bookpebble.yhlin06.workers.dev/ 。從 Threads、LINE 等內建瀏覽器進來時，改用 Safari，或複製網址貼入 Safari。
2. 點「分享」（方框上有向上箭頭）→「加入主畫面」。找不到時往下滑或選「更多」。
3. 若有「以網頁 App 開啟」選項，將它開啟，再按「加入」。
4. 從手機新出現的「繪本小聚場」圖示開啟；第一次可能需要登入。可在這個主畫面版本輸入信中的驗證碼，確保登入的是這個入口。

### Android

用 Chrome 開啟網站 → 右上角「⋮」→「新增至主畫面」或「安裝應用程式」。支援安裝提示的瀏覽器也會在說明內提供安裝按鈕，只在使用者點擊後呼叫。

加入主畫面後可使用圖示回訪。目前仍需網路才能讀取書單或送出內容；未提供離線書單，也未新增推播或自動寄信。不同瀏覽器與作業系統的選單、快捷選項支援會不同，仍需在實機確認。

## 隨手記心得

手機底部固定提供：

- 「找書」：回到全部已公開繪本，清除上次搜尋及篩選。
- 「記心得」：登入後進入原有分享表單，帶回目前帳號的文字草稿；未登入時完成登入後會回到表單。
- 「我的書架」：查看收藏，清除先前搜尋及篩選，避免誤以為收藏遺失。

開啟表單及其他視窗時，底部導覽會隱藏，避免遮擋輸入區。桌面保留原有導覽。

輸入書名、心得、作者、孩子反應、陪讀建議、主題、畫風、年齡及階段選項時，會立即儲存目前帳號的草稿。關閉、重新整理或稍後開啟同一瀏覽器，以同一帳號進入分享表單即可續寫；編輯已發布推薦的視窗不使用這份草稿。

文字草稿以 `pb-recommend-draft:<user-id>` 儲存在本機 localStorage，不寫入 Supabase，不會自動公開，不含登入憑證、Email 或照片。登出後不顯示前一帳號的草稿；切換帳號時載入各自的草稿。這是介面上的帳號區分，本機瀏覽器儲存本身並未加密。

照片與照片確認勾選不會跨次保存，關閉後需重新選擇。清除瀏覽器資料會移除草稿；不同手機、瀏覽器及主畫面版本可能不共用資料，尚未提供雲端草稿同步。瀏覽器無法儲存時會顯示提示，仍可繼續填寫及送出。

按「清除這份草稿」會先確認，取消則保留。送出失敗保留草稿，成功後清除；非管理者投稿仍先送審，管理者投稿仍直接公開。單純暫存不會上傳照片、建立書籍或觸發通知。
