# 用關鍵字搜尋繪本

直接在書單的搜尋框輸入關鍵字，不需開啟篩選器。

輸入的詞**不限定在篩選器或預設清單裡**。任何新詞只要出現在書籍文字或自訂標籤中，就能搜尋，不必新增同名情境。既有相近用詞對照只是輔助；搜尋本身不依賴預先列好所有關鍵字。全程使用一般文字比對，不需要 AI 服務或新增搜尋後端。

| 輸入範例 | 查找方式 |
|---|---|
| 任意書名片段或作者姓名 | 直接搜尋書名與作者 |
| 心得、孩子反應、陪讀建議中的詞 | 直接搜尋已填寫的書籍文字 |
| 任意自訂主題或畫風 | 自動納入搜尋，不需先新增篩選選項 |
| 天馬行空、腦洞大開、有創意（任選一種輸入） | 比對「想像與創作」及同組用語，例如想像力、創造力、創意 |
| 有創意 水彩 | 同時符合創意相關用語與水彩的書 |
| 手足相處 | 同時比對手足、兄弟姊妹等既有相近用語 |
| Chris、完整書名 | 也保留書名與作者的文字搜尋 |
| 幼幼班 | 比對書籍已有的階段建議 |

## 使用方式

- 搜尋範圍包含書名、作者、推薦心得、孩子反應、三段陪讀建議、注意事項、主題、畫風、語言、台灣作家標示，以及已有家長投票的年齡與階段。只顯示原本有權瀏覽的書，不會公開審核中的他人投稿。
- 同組用語採「任一符合」；多個關鍵字採「全部符合」。空白、全形空白、逗號及頓號可分隔關鍵字，例如「有創意、水彩」與「有創意 水彩」相同。
- 英文不分大小寫，全形英數字也可搜尋。未收錄的關鍵字仍按文字比對，不會自行猜測意思。
- 搜尋框下方的「也會找」提示會列出識別到的相近方向。這不會替你勾選篩選器或改寫書籍標籤。
- 可同時保留語言、年齡及其他篩選；按「全部繪本」會一起清除。搜尋框的 × 只清除文字搜尋，保留其他條件。
- 按鍵盤的搜尋／Enter 會移到結果及「全部繪本」入口；中文輸入法確認選字時不會提早跳走。

這是依現有書籍資料比對的搜尋。書籍若沒有包含輸入的關鍵字或已知相近用詞，就顯示 0 本，不會自行猜測書籍內容。新投稿的文字與標籤在載入書庫時會自動納入搜尋；不需修改程式或分類清單。

## 本次更新上線

本次僅修改網站，**不需要執行新的 Supabase SQL**。

1. 下載本次關鍵字搜尋版 ZIP。
2. [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Workers & Pages** → **bookpebble** → **Deployments** → **New deployment**。
3. 上傳新版 ZIP 並部署，然後開啟 https://bookpebble.yhlin06.workers.dev/ 重新整理。
4. 確認搜尋框顯示「搜尋書名、作者或任意關鍵字」。從已上架書籍的心得或陪讀建議挑一個沒有列在情境清單中的詞，應能直接搜尋到該書。書庫沒有相關文字時，0 本是正常結果。

ZIP 最外層須是 `index.html`、`styles.css`、`config.js` 與 `assets/reading-garden.svg`。GitHub 主分支更新不會自動更新 Cloudflare 的手動部署。
