# 用想找的方向搜尋繪本

直接在書單的搜尋框輸入關鍵字，不需開啟篩選器。

| 輸入範例 | 查找方式 |
|---|---|
| 天馬行空、腦洞大開、有創意（任選一種輸入） | 比對「想像與創作」及同組用語，例如想像力、創造力、創意 |
| 有創意 水彩 | 同時符合創意相關用語與水彩的書 |
| 手足相處 | 同時比對手足、兄弟姊妹等既有相近用語 |
| Chris、完整書名 | 也保留書名與作者的文字搜尋 |
| 幼幼班 | 比對書籍已有的階段建議 |

## 使用方式

- 搜尋範圍包含書名、作者、推薦心得、孩子反應、主題、畫風及家長階段建議。只顯示原本有權瀏覽的書，不會公開審核中的他人投稿。
- 同組用語採「任一符合」；多個關鍵字採「全部符合」。空白、全形空白、逗號及頓號可分隔關鍵字，例如「有創意、水彩」與「有創意 水彩」相同。
- 英文不分大小寫，全形英數字也可搜尋。未收錄的關鍵字仍按文字比對，不會自行猜測意思。
- 搜尋框下方的「也會找」提示會列出識別到的相近方向。這不會替你勾選篩選器或改寫書籍標籤。
- 可同時保留語言、年齡及其他篩選；按「全部繪本」會一起清除。搜尋框的 × 只清除文字搜尋，保留其他條件。
- 按鍵盤的搜尋／Enter 會移到結果及「全部繪本」入口；中文輸入法確認選字時不會提早跳走。

這是依現有資料和同義詞清單比對的搜尋，不會自行閱讀未提供的書籍內文。書籍若沒有相關標籤或推薦文字，可能顯示 0 本；不會拿無關的書填入結果。投稿時可補充主題及心得，讓其他家長更容易搜尋。
