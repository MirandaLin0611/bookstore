# 繪本小聚場

家長分享、篩選繪本的網站：英文／中文繪本、家長投票決定適合的年齡與階段、陪讀指南、台灣作家標示、收藏與閱讀紀錄、部分書籍開放集氣開團（不處理金流）。

第一版以累積共讀內容、推薦與交流為主，頁面不提供外部書店購買連結或聯盟行銷提示。保留管理者針對特定書籍開放的集單、集氣及開團通知，讓有興趣的家長自行參與。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 網站頁面與互動邏輯 |
| `styles.css` | 網站排版、手機版與介面樣式 |
| `mobile.js` | 主畫面加入說明、手機快捷入口、帳號各自的本機文字草稿 |
| `manifest.webmanifest` | 主畫面名稱、圖示、開啟方式及支援瀏覽器的快捷入口 |
| `assets/reading-garden.svg` | 首頁共讀插畫（本地檔案，不依賴外部圖床） |
| `assets/bookpebble-icon.png` | 沿用網站圖示，供手機主畫面使用 |
| `config.js` | 資料庫連線設定（Project URL 與 Publishable key，可公開） |
| `schema.sql` | 資料庫結構與權限規則，新資料庫先執行 |
| `patch1.sql` | 補丁，在 schema.sql 之後執行 |
| `patch2.sql` | 擴充「幼幼班」階段，既有資料庫也需執行一次 |
| `patch3.sql` | 啟用投稿人及管理者的安全編輯功能，既有資料庫需執行一次 |
| `patch4.sql` | 新增每本書的集氣補充說明，既有資料庫需執行一次 |

## 本機預覽

在專案資料夾執行 `python -m http.server 8000`，開啟 `http://localhost:8000`。不需要安裝前端套件或編譯。資料讀取使用 `config.js` 指定的 Supabase；本機測試登入前，需在 Supabase 設定允許的重新導向網址。

部署時保留 `index.html`、`styles.css`、`config.js`、`mobile.js`、`manifest.webmanifest` 與 `assets/` 的相對位置；不需上傳 SQL、文件或測試。現行正式站是 [BookPebble](https://bookpebble.yhlin06.workers.dev/)，使用 Cloudflare Workers 靜態檔案上傳；GitHub 程式碼更新不會自動更新這個網址。啟動、資料庫與上傳步驟見 [SETUP.md](SETUP.md)。

手機版提供固定的「找書／記心得／我的書架」入口，以及加入手機主畫面的操作說明。心得文字與選項會以登入帳號分開暫存於本機瀏覽器，關閉後可繼續填寫；照片不跨次保存，草稿不會自動投稿或跨裝置同步。這項更新不需要 SQL。操作及限制見 [手機回訪與文字草稿](docs/mobile-access.md)。

「幼幼班」投稿及投票需要 `patch2.sql`；既有資料庫若尚未執行，請先套用這份補丁，不要重跑 `schema.sql`。已執行者不需重跑。關鍵字搜尋本身不需額外 SQL。階段更新說明見 [篩選與書單更新步驟](docs/browse-update.md)。

本版新增每本書的集氣補充說明，已完成內容編輯更新的網站，請先在原 Supabase 專案執行 `patch4.sql`，再上傳新版。集氣期間會顯示不保證成團、達標後才洽詢出版社的通用說明；管理者可到帳號 →「集單與開團管理」，分別儲存各書的補充文字，留空即只顯示通用說明。補丁會替現有《If you cry like a fountain》填入英文版缺貨、國外供書待確認的初始說明，不更動集氣人數、狀態或開團備註。之後可直接在後台修改，不需再改程式。

投稿人及管理者可在書籍詳情點「編輯我的推薦／編輯繪本推薦」，修改文字、標籤、照片與陪讀建議；原書籍身分、狀態、收藏、留言、投票及集單紀錄保留。尚未啟用此功能者需先執行 `patch3.sql`。完整說明見 [編輯與集單操作](docs/editing-and-groups.md)。

開團操作會建立站內通知及 `notification_outbox` 紀錄，目前未接上集單通知信的自動寄送服務；電子郵件需由主辦人另行寄送。Supabase 的登入寄信設定不會自動寄出這類通知。

登入只需 Email，暱稱在登入後的帳號設定儲存。跨裝置驗證碼的信件模板設定及登入回歸測試，見 [Email 登入說明](docs/email-login.md)。

生活情境共六組、32 種，篩選與投稿共用相同選項。分類參考、別名對照及資料處理方式，見 [生活情境分類](docs/situation-filters.md)。

篩選使用獨立視窗，底部固定提供結果數及「全部繪本」入口。階段包含幼幼班；畫風與特色提供 12 種固定選項，另保留既有自訂標籤，投稿也能勾選。

一般關鍵字搜尋不限定在情境清單：書名、作者、心得、孩子反應、陪讀建議、注意事項和自訂標籤都能直接搜尋，新投稿的詞會隨資料自動納入，不需逐一新增情境。不需要 AI 或搜尋後端。搜尋範圍、相近用詞與上傳新版的步驟見 [關鍵字搜尋說明](docs/keyword-search.md)。

## 安全提醒

`config.js` 只能放 Publishable key。**Secret key（sb_secret_ 開頭）絕對不要放進任何檔案或上傳到 GitHub。**
